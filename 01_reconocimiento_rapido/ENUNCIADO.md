# Reto 1 — Reconocimiento rápido

Tiempo: 15 minutos.

Reciben un repositorio desconocido. Sin modificar el código, identifiquen:

1. Lenguaje y framework.
2. Archivo/módulo de arranque.
3. Endpoints.
4. Variables de entorno.
5. Dependencias externas.
6. Comando correcto para ejecutarlo.
7. Endpoint que demuestra liveness.
8. Dependencia que condiciona readiness.

Entregables:
- Diagrama simple.
- Lista de variables.
- Comando de ejecución.
- Lista de endpoints.
- Explicación de liveness vs readiness.
