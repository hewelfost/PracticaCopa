# Reto 1 — Reconocimiento rápido

Tiempo: 15 minutos.

Reciben un repositorio desconocido. Sin modificar el código, identifiquen:

1. Lenguaje y framework. [x]
2. Archivo/módulo de arranque. [x]
3. Endpoints. [X]
4. Variables de entorno. [X]
5. Dependencias externas. [x]
6. Comando correcto para ejecutarlo. [x]
7. Endpoint que demuestra liveness. [x]
8. Dependencia que condiciona readiness. [x]

Entregables:
- Diagrama simple.
- Lista de variables.
- Comando de ejecución.
- Lista de endpoints.
- Explicación de liveness vs readiness.
