# Reto 4 — Observabilidad y causa raíz

Tiempo: 35 minutos.

Una API responde HTTP 500 de forma intermitente.

Objetivo:
1. Generar tráfico normal y fallido.
2. Identificar qué endpoint produce 500.
3. Usar logs y, una vez desplegada, Application Insights/KQL.
4. Corregir la causa.
5. Validar nuevamente.

Entregables:
- Endpoint/request problemático.
- Evidencia en logs o App Insights.
- Consulta KQL que muestre fallo/excepción.
- Commit del fix.
